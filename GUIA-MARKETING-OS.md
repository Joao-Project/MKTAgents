# Guia Rápido - Marketing OS

Este workspace combina o Kai CMO Harness com uma camada própria para o Achadinhos do Bebê em `marketing/`.

## Como Usar

Mantenha estes arquivos como fonte principal:

- `marketing/strategy/BRAND.md`: marca, voz, posicionamento e limites.
- `marketing/strategy/AUDIENCE.md`: público, dores, desejos e objeções.
- `marketing/products/products.csv`: banco de produtos.
- `marketing/content/ideas/ideas.csv`: banco de ideias.
- `marketing/analytics/TESTS.md`: experimentos.
- `marketing/analytics/LEARNINGS.md`: aprendizados.
- `marketing/analytics/WINNERS.md`: vencedores.
- `marketing/analytics/CONTENT_HISTORY.md`: histórico de conteúdos.

## Regra de Ouro

O agente não deve criar posts aleatórios. Ele deve primeiro entender produto, público, problema, ângulo, formato e CTA.

Quando houver dados reais, use dados reais. Quando faltar informação, declare a hipótese e marque para validação.
