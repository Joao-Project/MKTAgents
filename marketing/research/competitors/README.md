# Pesquisa de Concorrentes

Guarde aqui análises de concorrentes, padrões de conteúdo, hooks, CTAs, ofertas, comentários e oportunidades.

Para cada análise, responda:

- O que está funcionando?
- O que está saturado?
- O que podemos fazer diferente?
- Quais lacunas existem?
- Que ideias podemos adaptar sem copiar?
