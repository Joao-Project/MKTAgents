# Modelos

Modelos reutilizáveis para briefings, avaliações de produto, Reels, carrosséis, Stories, análises de resultado e planejamento semanal.

## Briefings de produção

Começar pelo [briefing-base](content-brief.md) e aplicar a [direção criativa](../strategy/DIRECAO-CRIATIVA.md).

- [Post estático](briefing-post.md): uma situação, um produto e uma mensagem.
- [Carrossel](briefing-carrossel.md): capa, sequência editorial e contagem de produtos.
- [Stories](briefing-stories.md): sequência curta, interação e destino.
- [Reel](briefing-reel.md): cenas, demonstração, texto e narração.
- [Exemplo preenchido de carrossel](../content/briefings/2026-09-22-curadoria-cuidados.md): aplicação das referências com lacunas registradas.

Os modelos orientam a produção; campos preenchidos não equivalem a aprovação ou publicação. Não inventar dados para completar um modelo.
